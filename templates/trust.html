Trust and privacy

Payment-risk scans should be explainable, private, and easy to erase.

PayShield is the customer payment-risk app for finance teams handling sensitive supplier emails. It keeps invoice, bank-detail, and payment release decisions inside a signed-in workspace.

Data use

Uploads are for analysis, not model training

Uploaded emails are used to produce the requested risk result and workspace history. They are not added to training datasets or public demos.

Retention

Stored results have deletion and purge controls

Workspace scan history can be deleted from the app. Production retention tooling also supports purging older SaaS scan, lock, usage, and audit rows.

Third parties

Plan-gated checks are visible

Paid checks such as URL reputation, domain intelligence, attachment sandboxing, browser detonation, and LLM reasoning are only run when the workspace plan allows them.

Authentication

Owner admin access supports user-bound passkeys

Customer workspaces use email and password login with CSRF-protected actions. Only an explicitly allowlisted platform owner/admin can enter private admin routes after a fresh passkey step-up. Tenant owner role alone is not enough. Internal bearer clients remain compatible.

Mailboxes

Mailbox access requires explicit connection and opt-in

The app does not read a mailbox just because a user signs in. A signed-in user can explicitly start Scan now using a connected account, encrypted credentials, and plan permission. Continuous monitoring is a separate Pro or Business opt-in for each mailbox and can be turned off at any time.

Security

Sensitive capabilities stay gated

Live analysis, billing, stored history, feedback learning, and mailbox Scan now stay behind normal user authentication or private analyst authentication, depending on the surface.

Operations

Payment-risk alerts omit invoice content

High-risk decisions, repeated campaigns, analyzer outages, and login throttling can notify operators without email addresses, subjects, URLs, message content, client IPs, or raw workspace identifiers.
